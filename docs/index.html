01 Establish comparable features ＋

I converted histology patches to grayscale, resized them to 32 × 32 pixels, and aligned them with 38 protein measurements.

Why this choice: compact inputs make classical models tractable. Training-only scaling prevents test-set statistics from entering preprocessing for the held-out experiments.

Data alignmentStandardScaler
02 Understand the feature spaces ＋

PCA retained approximately 90% of variance with 20 protein components versus 336 image components. NMF extracted four latent patterns in each space.

Why this choice: inspect dimensionality and structure before fitting predictive models. The image space needs substantially more components to preserve comparable variance.

03 Test a simple biological signal ＋

I separated HED stain channels and tested hematoxylin intensity against cMYC expression, including a regression controlling for specimen identity.

What it showed: the association remained statistically significant, but the model R² was only about 0.003. Statistical significance did not translate into meaningful explanatory power.

04 Compare classical and deep learning ＋

A Random Forest used PCA-reduced features to predict CDK4. A two-layer CNN learned directly from image patches to predict cMYC.

Why this choice: explore engineered versus learned representations. These models target different proteins, so their scores are not a controlled architecture comparison.

Random ForestPyTorch CNN
05 Evaluate beyond a single specimen ＋

I extended the CNN to 38 outputs and used leave-one-specimen-out cross-validation: train on three specimens and test on the fourth, repeated four times.

Why this choice: an unseen specimen is a harder test of generalisation than another patch from a specimen already seen during training.

The multi-target notebook refits its image scaler inside each training fold. The four-specimen dataset still limits the strength of generalisation claims.

02 / IMPLEMENTATION

Learn features from the pixels

Two convolutional stages learn local image patterns. A 128-unit layer maps the flattened representation to one cMYC regression output.

Read the complete notebook
CNN architecture Python
class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()

        self.conv1 = nn.Conv2d(in_channels=1, out_channels=32, kernel_size=3, padding=1)

        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)

        self.conv2 = nn.Conv2d(in_channels=32, out_channels=64, kernel_size=3, padding=1)

        self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)



        self.fc1 = nn.Linear(64 * 8 * 8, 128) 
        self.fc2 = nn.Linear(128, 1) 

    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = self.pool2(torch.relu(self.conv2(x)))
        x = x.view(-1, 64 * 8 * 8) 
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x

The outcome is a research pipeline and a clearer picture of what image-based prediction can—and cannot—support.

PROJECT SCOPE

Academic, exploratory work. No clinical deployment, cost savings, or patient outcomes were measured.

01

An end-to-end experimental foundation

Connected image processing, statistical analysis, classical ML, and deep learning in one notebook with inspectable outputs.

02

Evidence of useful—but limited—signal

Demonstrated moderate held-out rank correlations for CDK4 and cMYC while making the limitations in absolute accuracy explicit.

03

A concrete next-experiment plan

Repeat the existing fold-specific preprocessing and evaluation across multiple seeds, establish consistent baselines, then test pretrained image encoders and spatial context.

What I would improve before calling this production-ready ＋

Evaluation hygiene: preserve the existing fold-specific image scaling, repeat training with multiple seeds, and add uncertainty estimates across repeated runs.

Comparable baselines: evaluate architectures on the same protein targets and splits. The notebook’s final consolidated table contains overwritten Random Forest metric variables; this site uses the dedicated CDK4 evaluation output.

Reproducibility: replace notebook-specific paths with configuration, pin dependencies, save model checkpoints, and add data-alignment checks.

Generalisation: evaluate on more independent specimens before making claims beyond these four. Clinical use would require a separate validation programme.
